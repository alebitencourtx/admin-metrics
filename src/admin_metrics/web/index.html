Como ler este painel

As métricas dos serviços são autodeclaradas pelo Santander. A média ponderada usa Σ(média × chamadas) / Σ(chamadas) apenas para linhas válidas com tráfego; não é p95. Erro e rejeição usam seus próprios denominadores válidos. A cobertura pode variar entre ciclos.

Os reportes operacionais podem compartilhar serviços. O agregado é a soma dos reportes selecionados, sem garantia de transações únicas entre instituições.

O dia analítico usa o HTTP Date da página que produziu cada linha em America/Sao_Paulo; páginas que cruzam o dia tornam a captura incompleta. O requestTime original é preservado. O relatório não identifica cada status HTTP de erro e não determina a causa de rejeições.

Somente os oito endpoints Admin são consultados. Nenhuma chamada é feita aos endpoints de clientes ou pagamentos listados.

Regras analíticas configuráveis

Amostragem de uma hora pode perder incidentes breves. Agendamento GitHub Actions é best effort; o aviso de atraso usa a idade real da última coleta. Não é um laudo de conformidade regulatória.

Gráficos com janela de 3 dias; histórico normalizado de 30 dias nas Releases; bronze das duas coletas recentes. Dois estados aprovados em Releases permitem recuperação.
